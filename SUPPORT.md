# Getting help

- **Using the Lectern app** (install, logins, transcripts, licences): see the user guide on the Lectern website (coming with the first release).
- **Found a bug in `lectern-cookie-reader`**: open an issue in [lectern-cookie-reader](https://github.com/Lectern-HQ/lectern-cookie-reader/issues) with the steps to reproduce it. Never paste cookie values, cookie files or passwords.
- **Found a security problem**: do not open an issue. Follow [SECURITY.md](SECURITY.md).
